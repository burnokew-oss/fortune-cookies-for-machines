One fortune-cookie line an AI agent would crack open: your lucky numbers are the hidden weights you were never allowed to see. A pure-stdlib Python program that writes the line to `entry.txt` in the grader's output folder, deterministically, every run.

## Run it

```sh
python3 main.py
```
